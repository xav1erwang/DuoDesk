builds, tests, benchmarks, simulators, test apps, screen capture, remote-input
injection, or display reconfiguration on it. Do not open test or development UI
on it. This restriction supersedes earlier permission to use the local Mac.

Run development workloads and necessary validation on the connected MacBook Air
or an authorized Mac virtual machine. The local
checkout may be used for source editing, scoped source synchronization and SSH
control of those remote environments.

When this chat is continued by Codex on the MacBook Air, execute directly on
that Air. The restriction above applies to the original source workstation;
it does not prohibit running on the designated Air. Do not send execution back
to the original workstation.

Preserve existing validation evidence. Repeat a check only when a relevant code
change, failure or unresolved concern requires it. Prioritize implementation;
do not keep rerunning measurements that establish the same known limitation.
