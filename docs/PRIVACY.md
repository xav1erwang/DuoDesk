# DUO你电脑隐私说明

更新于 2026 年 11 月 7 日。本说明适用于本仓库提供的 DUO你电脑应用。

## 设备之间的数据

Mac 主机捕获并传输用户选择的桌面画面，处理手机发来的键盘、文字、触控板与鼠标操作。启用剪贴板共享后，所选剪贴板文本也会在设备之间传送。系统授权决定应用是否能访问屏幕、辅助功能、本地网络和相机。

应用通过用户配置的本地或远程网络连接自己的 Mac。正式应用使用配对和 TLS 身份校验，QUIC 与备用 TCP 均验证对端身份。项目没有运营用于转发桌面内容的公共服务。

相机用于扫描配对码。扫描流程在设备上处理图像。

## 本地保存

两端在本机保存设置、设备或主机信息和配对状态，身份密钥保存在系统钥匙串中。两端的「日志」开关控制近期运行日志的本地记录。日志可能包含设备名称、网络地址、连接状态、显示和性能诊断，不记录剪贴板文字或配对私钥。近期日志最多保留两份、每份 2 MB；关闭后不再追加，已有近期日志仍可导出。在「采集日志 → 用户反馈」中填写的可选问题描述与近期日志一同保存为用户选择位置的 JSON 文件，没有自动上传。主动导出的日志、截图或反馈附件可能包含个人信息，请在发送前检查。

删除应用后，系统钥匙串可能继续保留身份数据。要撤销设备访问，可在 Mac 的设备设置中取消配对。

## 外部服务

点击下载、帮助或隐私链接会访问 GitHub。源码通过 GitHub 获取，GitHub 根据自己的隐私政策处理网页与下载请求。当前 Mac 发行配置关闭自动更新检查。

Xcode 签名、Sideloadly、AltStore Classic、SideStore 与 Apple 账号登录由相应提供方处理。签名工具可能在本机保存 Team、设备标识、应用标识与签名日志；此类资料应留在自己的电脑上。

当前仓库没有集成第三方广告或分析 SDK。iOS 的隐私清单随应用提供，后续增加采集或服务时会同步更新本说明。

## 联系

一般隐私问题可在 [DuoDesk Issues](https://github.com/xav1erwang/DuoDesk/issues) 提出。涉及密钥、配对码、账号或安全漏洞时，请依照 [安全报告说明](../SECURITY.md) 使用维护者的私人报告渠道。
